## Follow-up clarification: Does roboRIO use WPILib?

**Yes. roboRIO robot programs already use WPILib. Systemcore does not introduce WPILib for the first time.** WPILib is the software library used by the robot application, not the controller's operating system. The official stable documentation identifies WPILib as the standard FRC library and documents deployment of robot programs to roboRIO. [F01](#f01) [F02](#f02)

| Part | Role |
|---|---|
| Student robot program | Defines the team's robot behavior |
| WPILib and applicable vendor libraries | Supply robot programming APIs and device integration |
| roboRIO or Systemcore | Physical controller on which the appropriate robot program runs |

This is a conceptual separation, not a full internal software or electrical diagram. See [the comparison](../ROS2_COMPARISON.md) for ROS 2 and NetworkTables distinctions.

The 2027 change is a controller transition accompanied by WPILib updates. Its official changelog requires importing previous projects and records hardware/API changes. Being in the same ecosystem does not mean an old binary, installer, or project runs unchanged on the new controller. [F03](#f03)

**Project implication, our recommendation:** teach shared robot-programming concepts once, then explicitly document the controller-specific and release-specific differences. This strengthens the case for reusing WPILib simulation rather than creating another general simulator. No implementation or hardware test was performed for this clarification.
