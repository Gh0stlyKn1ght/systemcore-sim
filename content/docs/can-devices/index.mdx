# Module 05: CAN and devices

**Status:** Planned.

## Students will be able to

- explain CAN as a shared communications bus rather than a motor-power wire;
- distinguish a device ID from a Java object name;
- separate configuration applications, robot-code libraries, and device firmware;
- identify duplicate-ID and wrong-bus failure patterns; and
- document a device before changing its firmware or configuration.

## Planned practical

Build a device responsibility matrix, diagnose a synthetic duplicate-ID fault, and explain which claims can be made without a physical CAN interface.
