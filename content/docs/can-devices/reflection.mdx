## Correct two claims

For each selected claim, write a correction and cite source or run evidence.

1. “CAN wires power the motor.”
2. “Every device numbered 3 is a duplicate.”
3. “If the configuration application sees it, Java can use it.”
4. “Installing the vendor application updates every robot project.”
5. “A successful build proves the CAN wiring is correct.”
6. “The roboRIO/PDP termination diagram can be copied directly to Systemcore.”
