# Module 06: NetworkTables and telemetry

**Status:** Planned.

## Students will be able to

- describe topics, publishers, subscribers, and the usual robot-server arrangement;
- choose telemetry that explains a decision instead of flooding the dashboard;
- keep value, timestamp, validity, and source together;
- distinguish a displayed number from a fresh observation; and
- use AdvantageScope or Elastic for the job each tool is designed to perform.

## Planned practical

Publish a target observation with age and validity, stop updating the source, and verify that the dashboard exposes the stale state instead of silently showing an old “good” value.
