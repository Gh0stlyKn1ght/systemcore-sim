# Module 08: automated testing

**Status:** Planned.

## Students will be able to

- write a requirement as arrange, act, and assert;
- distinguish a build check from a behavioral test;
- test neutral input, output bounds, cancellation, and stale-data fallback;
- confirm that a deliberately wrong expectation actually fails; and
- read a test failure without editing the assertion merely to make it green.

## Planned practical

Complete a small JUnit suite for drive requests, break one requirement intentionally, and use the report to locate the behavior defect.
