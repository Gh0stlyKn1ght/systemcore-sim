# Module 08: automated testing

**Status:** Complete first edition.

## Module outcomes

- separate unit, integration, simulation, and hardware tests;
- write Arrange-Act-Assert checks with one named reason for failure;
- generate boundary tables instead of testing one happy path;
- express invariants across many inputs;
- prove a test can detect a deliberate mutation; and
- preserve a regression case after correcting a defect.

## Two test layers

The repository runs hardware-free Java checks through source-file mode. A generated WPILib robot project should translate permanent contracts into JUnit 5 tests. WPILib Java projects include JUnit 5 support, but imports and project layout must match the installed 2027 release.
