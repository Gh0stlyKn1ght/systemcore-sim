# Reflection and corrections

Correct each claim using an evidence boundary:

1. “The project builds, so the behavior is correct.”
2. “One happy-path test covers the requirement.”
3. “A hardware test is always better than a unit test.”
4. “If the test fails, change the expected result.”
5. “The 100 ms case is redundant if 99 and 101 pass.”
6. “A passing invariant proves every integration.”
7. “A test suite is strong even if no mutation can make it fail.”
8. “Random failures are acceptable in robot tests.”
9. “JUnit imports from 2026 can be copied unchanged into any 2027 alpha.”
10. “A corrected defect no longer needs its regression case.”

## Synthesis

Build an evidence ladder for “autonomous always returns drivetrain output to neutral.” Include pure unit, sequence integration, desktop simulation, and hardware evidence.
