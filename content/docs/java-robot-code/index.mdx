# Module 03: Java robot code

**Status:** Planned.

## Students will be able to

- translate a plain-language robot requirement into inputs, decisions, and outputs;
- keep decision logic separate from hardware access;
- use records or small value objects for observations and requests;
- handle invalid input explicitly; and
- make a behavior small enough to test without the full robot.

## Planned practical

Implement a drive-request calculator with deadband, scaling, output limits, and a neutral fallback. The first version will contain an intentional boundary bug for students to find.
