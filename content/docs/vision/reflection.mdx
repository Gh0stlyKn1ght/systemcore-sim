# Reflection and corrections

Correct each claim:

1. “If a target is visible, its result is safe to use.”
2. “The latest received message must describe the current scene.”
3. “Capture time and receive time are interchangeable.”
4. “A future timestamp is fresher than a current one.”
5. “Finite numbers prove the coordinate frame is correct.”
6. “Low ambiguity grants permission to move.”
7. “A camera yaw can also be used as a field-relative pose.”
8. “Pose-estimator latency compensation makes every old measurement useful.”
9. “The vision pipeline should write directly to motor output.”
10. “Passing synthetic checks proves camera calibration and field accuracy.”

## Synthesis

Define the complete acceptance rule for one selected camera observation. Name the producer, time base, coordinate frame, units, quality evidence, authorized consumer, bounded output, rejection behavior, and hardware evidence still required.
