# Module 10: vision inputs

**Status:** Planned.

## Students will be able to

- separate image capture, target processing, data transport, and robot behavior;
- define coordinate frame, units, timestamp, and validity for an observation;
- calculate observation age;
- reject stale or contradictory target data; and
- preserve one clear authority for motion requests.

## Planned practical

Feed synthetic target offsets into the Java application, freeze the source, and confirm the aiming helper stops trusting the retained value.
