# Module 10: vision inputs

**Status:** Complete first edition.

## Module outcomes

- separate image capture, target processing, data transport, and robot behavior;
- define coordinate frame, units, timestamp, and validity for an observation;
- calculate observation age;
- reject stale, impossible, low-quality, or unauthorized target data;
- distinguish an aiming correction from a global pose measurement; and
- preserve one clear authority for motion requests and estimator updates.

## Executable boundary

The Java example models the decision boundary after a camera pipeline has produced a result. It does not process pixels, calibrate a camera, or claim real pose accuracy. Those require a selected camera, an AprilTag field layout, calibration, compatible vendor software, and measured hardware evidence.
