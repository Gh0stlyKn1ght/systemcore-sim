# Module 02: WPILib foundations

**Status:** Next module to build.

This module moves from the controller stack into the framework that calls the team’s Java code.

## Students will be able to

- locate the entry points in a generated Java robot project;
- explain initialization, disabled, autonomous, teleop, and test modes;
- distinguish periodic callbacks from one-time initialization;
- identify which state should persist and which state should reset; and
- trace one value from Driver Station input to a bounded application request.

## Planned module evidence

Students will annotate a lifecycle trace, change one Java behavior, build the project, and explain why disabled code can still execute while actuator requests remain restricted.

## Planned practical

Create a mode reporter that publishes current mode, transition count, and time since transition. Then introduce a reset bug and diagnose it from telemetry.
