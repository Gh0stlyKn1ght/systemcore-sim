# Module 04: Driver Station

**Status:** Planned.

## Students will be able to

- identify which work happens on the operator computer and which runs on the controller;
- separate joystick input, mode control, network connectivity, and robot-code status;
- explain why enabled, connected, and code-running are different conditions; and
- trace a joystick request without treating NetworkTables as the entire control path.

## Planned practical

Diagnose four prepared status scenarios: no joystick, no communications, no robot code, and disabled robot. Students must choose the correct layer before proposing a fix.
