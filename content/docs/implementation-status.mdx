## Evidence boundary

The repository currently proves prepared Java behavior, telemetry classification, deterministic modeled motion, automated regression rules, and autonomous termination under modeled conditions.

It does not yet prove final WPILib 2027 API compatibility, deployment to production Systemcore hardware, real CAN topology, vendor-device compatibility, controller timing, electrical behavior, mechanism motion, or vision accuracy.

## Hardware plan

Start on existing supported classroom computers. Raspberry Pi 5 kits are optional shared coprocessor stations. A Pi does not replace Systemcore. Physical validation waits for supported controller hardware, compatible vendor releases, reviewed power and CAN topology, and a bounded first-power procedure.

See [Build the Systemcore Lab](/docs/build-guide) for the staged bill of materials and [Course Map](/docs/course-map) for the learning sequence.
