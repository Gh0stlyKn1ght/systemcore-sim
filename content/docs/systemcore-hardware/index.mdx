# Module 11: Systemcore hardware

**Status:** Planned and blocked on selected hardware, compatible releases, and a reviewed bench procedure.

## Students will be able to

- identify the controller image, WPILib version, vendor library, tool, and firmware involved in a test;
- deploy the known-good Java example using the supported workflow;
- validate one input and one bounded output safely;
- compare measured behavior with simulation assumptions; and
- record corrections without treating one result as universal hardware parity.

## Planned practical

Repeat the first simulated behavior on a bounded bench setup, record the exact software and firmware profile, and document every observed difference.
