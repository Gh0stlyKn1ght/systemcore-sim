# Reflection and corrections

2. “Twenty milliseconds of wall time always equals one 20 ms simulation step.”
3. “Equal motor requests guarantee straight real-world travel.”
4. “A reversed encoder means the physics model must run backward.”
5. “A frozen heading value is safe because it is still a valid number.”

8. “Passing repository checks proves WPILib integration.”

10. “One successful run is enough evidence.”
