# Module 07: desktop simulation

**Status:** Planned.

## Students will be able to

- explain what desktop simulation replaces and what it does not;
- supply simulated joystick, encoder, heading, and mode inputs;
- connect behavior code to a simple drivetrain model;
- inspect telemetry from a repeatable run; and
- avoid describing animation as proof of wiring, power, or timing.

## Planned practical

Drive a differential robot in simulation, record a baseline, reverse one modeled encoder, and diagnose the resulting disagreement between command and observation.
