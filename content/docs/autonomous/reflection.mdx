# Reflection and corrections

Correct each claim:

1. “Autonomous can stop after a fixed delay because the robot probably arrived.”
2. “A completed routine can keep its last motor request.”
3. “Cancel only needs to work from the first state.”
4. “Fresh data is always valid and authorized.”
5. “A failed routine should resume automatically when data returns.”
6. “One boolean is enough to explain every terminal result.”
7. “Simulation completion proves real distance and heading.”
8. “Path planning should be added before a two-step routine works.”
9. “Commands v3 removes the need for behavior contracts.”
10. “Timeout and success are equivalent because both stop the step.”

## Synthesis

Define the state, success rule, timeout, observation contract, output request, and terminal reason for an autonomous approach to a vision target. Identify which parts belong to Module 10.
