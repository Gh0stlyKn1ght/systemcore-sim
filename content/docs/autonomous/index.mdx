# Module 09: autonomous behavior

**Status:** Planned.

## Students will be able to

- define the start, finish, interruption, and fallback conditions of an action;
- separate a behavior sequence from its hardware adapter;
- stop outputs when autonomous is canceled;
- inspect position and heading error over time; and
- explain when path-planning tools add value and when they add unnecessary complexity.

## Planned practical

Run a short timed or distance-bounded routine, cancel it mid-run, and verify through tests and telemetry that outputs return to neutral.
