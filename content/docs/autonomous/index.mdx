# Module 09: autonomous behavior

**Status:** Complete first edition.

## Module outcomes

- represent a routine as explicit states and transitions;
- give every moving state a completion condition and timeout;
- end, cancel, or fault into neutral output;
- distinguish modeled progress from elapsed time alone;
- record the active step, reason, and termination result; and
- test normal completion, timeout, stale input, and interruption.

## Framework boundary

The executable example uses a framework-neutral state machine. It can later be wrapped by the selected 2027 OpMode or command framework. Commands v3 is prerelease, so this module preserves behavior and termination contracts without requiring one alpha-specific scheduler API.
